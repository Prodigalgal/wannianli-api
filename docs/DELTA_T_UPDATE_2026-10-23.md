## 之后如何更新

离线复核已固定快照：

```sh
node tools/audit-delta-t.mjs
```

主动查询上游并另存本地证据：

```sh
node tools/audit-delta-t.mjs --fetch --sources build/sources/usno-latest --report build/validation/usno-latest.json
```

发现末次观测日期变化时报告`observationUpdateAvailable=true`并返回退出码2，不自动改算法。生成器现在验证日期真实、月序连续、不重不漏及末次日期严格匹配；如果上游新增了月份，必须先复核敏感日期再更新锚点，不能继续静默裁去新行并声称资料最新。HTTP失败或表格破损会失败退出，不当作“无更新”。

维护流程为：保存原始数据和哈希→判断实测/预测及版本→更新生成器锚点→两端测试、敏感日期和HKO全量对照→记录真实行为变化→构建部署。当前没有新实测锚点，因此天文结果保持原数值。
