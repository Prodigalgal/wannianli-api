## 第一批纳入16项

| 神名 | 卷十采用用途 | 特别限制 |
|---|---|---|
| 临日 | 上册进表章、上官赴任、临政亲民、陈词讼 | 不采旧引文的反向禁忌 |
| 驿马、天马 | 行幸、遣使、搬移（原文般移） | 天恩并才宜颁诏、宣政事；月恩/四相/时德并才宜诏命公卿、招贤。另有十月除日、五月成日与天马并的专条；不从旧说直接推荐出师 |
| 天后 | 求医、疗病 | 与驿马同位，单独记录用途，不继承全部旧说 |
| 兵吉 | 安抚边境、选将、训兵、出师 | 与既有专忌继续共同裁决 |
| 五富 | 经络、酝酿、开市、立券、交易、纳财、开仓库、出货财、栽种、牧养、纳畜 | 与月恩/四相/时德并才加修仓库 |
| 天仓 | 进人口、纳财、纳畜 | 与月恩/四相/开日并才加修仓库；不把时德列入该条件，不推荐捕捉 |
| 要安、敬安 | 安神 | 不继承前引修城、庆赐等用途 |
| 玉宇、金堂 | 修祠宇 | 不泛化成修宫室、婚姻 |
| 普护、福生、圣心 | 祭祀、祈福 | 圣心不单独推荐上表章 |
| 益后、续世 | 祭祀、祈福、求嗣 | 不单独推荐嫁娶、修置产室 |

共享规则增加16项，原29项扩至45项。这是共享表条目数，不是全书覆盖率，也不是每日吉神数量。起例的月份沿用节月支，不以农历月数字替换。新吉神不改变德神判定、日等或六等消解，仍受专忌、互注、无禄等铺注限制。

黄金表在`volume06-month-gods.json`，由原文日支另录为192个逐月单元；兵吉单元含四支。Java和Worker各验证12月×60日的720种组合，并验证作者撤回的用途没有从本条复活、指定神与错误替代神的正反例。双端全字段差分另行执行，不能仅以共享JSON相同作为算法一致证明。
