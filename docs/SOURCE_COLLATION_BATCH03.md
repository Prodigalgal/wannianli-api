- 三合：4a圆图十二月为巳、酉；4b正文刻作丑、巳。正文末项登记为底本疑讹。采用圆图及巳酉丑三合关系，现行算法正确排除月建本支，不按正文疑讹改成丑日。

- 月煞、月虚、月刑、月害、大时、天吏及此前16神的圆图补核，未发现本批需要改动的计算起例。图上的同位旧名，不自动当作新的独立神煞加入API。
