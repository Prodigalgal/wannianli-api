## 与计算实现对照

原表按影像独立录为`src/test/resources/fixtures/volume10-grade-table.json`，未从运行规则反向生成。Java和Worker分别检查表格完整性，并按2020—2024每天12:00的真实结果逐日对照。

1827日中1128日命中表列：其中1064日基础等第与计算结果一致，64日由卷十另列的阴阳专日、四废叠月破或天吏/大时遇四废岁薄逐阵等专例改变；每一差异必须落在明确例外中。重复命中多个表列时，所有列的基础等第一致，未采用加分、取最大值或任意优先级。剩余699日未命中这些表列，不能从空格编造等级；其中有些仍可由满/开日等逐项正文确定，其余保留未定。

本次核验没有发现既有35组逐月等第与原表的无解释冲突，因此不改动计算裁决。更新API/MCP 2.2.1的来源说明，删除“完整原表未找到”的过时限制。专忌、逐项解忌与铺注仍分别处理；找到这两页不等于完成全书影印校勘。
